# Security Policy

## Supported Versions

| Version | Supported |
|---|---|
| Latest version | Yes |
| Older versions | No |

## Reporting a Vulnerability

Please report security vulnerabilities privately to the project maintainers. Do not disclose vulnerabilities through public issues or discussions.

Include:

- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Affected component
- Proof of concept, if available

## Vulnerability Response Timeline

| Severity | Acknowledgment | Target Resolution |
|---|---:|---:|
| Critical | 24 hours | 7 days |
| High | 48 hours | 14 days |
| Medium | 5 business days | 30 days |
| Low | 7 business days | As resources permit |

## Security Requirements

- Do not commit API keys, passwords, tokens, or credentials.
- Store sensitive configuration in environment variables.
- Validate and sanitize user inputs.
- Apply proper authentication and authorization.
- Keep dependencies updated.
- Report vulnerabilities responsibly.
